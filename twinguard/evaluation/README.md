# evaluation
Each member writes the scripts for their own metrics.
- `twin_metrics.py` (Member 2): detection rate, false alarms, replay reproducibility
- `diagnosis_eval.py` (Member 3): diagnosis accuracy and confusion matrix
- `ledger_tests.py` (Member 4): tamper detection, gate correctness, evidence coverage
- `e2e_test.py` (Member 3): full scenario run
